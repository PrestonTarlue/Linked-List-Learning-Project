# C++ Linked List Learning Project

This repository contains my implementation of a Linked List data structure in C++. It demonstrates how to create custom structs, manage pointers, and traverse through nodes in memory.

## Code Overview
- **Structure**: Uses a `Car` struct to represent data nodes.
- **Features**: 
  - Dynamic linking of nodes using pointers.
  - Manual memory handling.
  - Traversal logic to iterate through the list and output data to the console.

## Structure
- `src/main.cpp`: Contains the implementation of the linked list and the traversal logic.
